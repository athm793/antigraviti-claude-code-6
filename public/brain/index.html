What it is

Two products in one app, the second built on the first:

  1. Key-rotation proxy — one provider = one upstream API + a pool of keys. Calls to /api/proxy/[configId]/… pass through with the next active key injected; a rate-limited key is benched and the next one used.
  2. Waterfall endpoints — one public URL runs an ordered list of steps, each calling a different provider, with JSON rule trees deciding whether a step runs and whether it answered. Try Prospeo → no email → try BetterEnrich → Hunter. One response shape whichever provider answers, plus per-provider hit rates.
