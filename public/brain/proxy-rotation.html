Proxy & rotation

How rotation works

src/lib/rotation.ts — executeWithRotation(config, req), shared by the pass-through proxy and the waterfall executor. It returns the upstream Response unconsumed plus keyId / attempts / keysExhausted / latency, so the proxy can stream it and the executor can parse it.

  • Selection is lowest order_index that is active — a pool drains in order; it is not round-robin. Under heavy concurrency several requests can land on the same key at once.
  • A response whose status is in the config's rate_limit_codes (restricted to 400–599 on save) benches the key: exhausted, or cooldown when cooldown_minutes > 0. markKeyExhausted returns whether it won the race.
  • excludeKeyIds keeps a retry from re-picking the key it just burned — shared across a whole waterfall run per provider.
  • Per-attempt AbortController timeout (PROXY_ATTEMPT_TIMEOUT_MS, default 30s), plus a deadlineAt hard stop; no attempt starts with <750ms left.
  • redirect: "manual", and callers treat 3xx as failure — chasing a Location the provider chose would send a live key somewhere nobody configured.

Header discipline

  • HOP_BY_HOP_REQUEST strips hop-by-hop, Vercel infra headers, and KeyProxy's own credentials (x-master-key, x-endpoint-key) so they never reach a vendor.
  • The provider's auth header is set last, so a caller-supplied header can never displace the injected key.
  • isWithinBase asserts the assembled URL is still on the provider's origin and base path before any fetch.

Cooldown recovery

recoverCooldownKeys(config) — hoisted to once per provider per run, so a five-step waterfall doesn't fire five of them. resetCooldownKeys uses RETURNING id (it used to return 0 unconditionally).

Proxy authentication

/api/proxy/[configId]/[...path] authenticates by the config's master_key (header x-master-key or Bearer). This is the legacy plaintext pattern; waterfall endpoint keys are the hashed replacement pattern (see Security). The debug route /api/debug/… is fail-closed behind ENABLE_DEBUG_ROUTE=true, rate-limited, and scrubs all output.
